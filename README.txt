WAXED ANTI-XRAY – Minecraft Java 1.21.11

Installation:
1. Die ZIP-Datei nicht entpacken.
2. Minecraft öffnen.
3. Optionen > Ressourcenpakete > Paketordner öffnen.
4. Waxed_AntiXray_1.21.11.zip hineinziehen.
5. Paket aktivieren.

Veränderte Blöcke:
- Stein und alle normalen Erzvarianten
- Tiefenschiefer und alle Tiefenschiefer-Erzvarianten
- Netherrack, Nethergolderz, Netherquarzerz
- Antiker Schrott

Wichtiger Hinweis:
Ein Ressourcenpaket ist kein echter serverseitiger Anti-Xray-Schutz.
Spieler können es deaktivieren oder ein anderes Paket bzw. einen modifizierten
Client verwenden. Für einen Paper-Server sollte zusätzlich die eingebaute
Anti-Xray-Engine aktiviert werden.
